# 林间绘本馆 · 故事改写稿

三本绘本均保留四幕。每次操作都有故事中的原因和可见结果；结尾的问题可以跳过，读完即可收下书签。

## 迷路的小星星

怕黑的露露答应送小星星去山顶。可它越着急，越走不出森林……

情节：怕黑却答应送星星回家 → 着急乱跑，绕回原处 → 看清脚边，一次走一小段 → 仍有点怕，也迈出回家的第一步。

### 第 1 幕：答应了一件难事

“山顶的晚风能送我回家。”灌木里的小星星说。露露刚伸出脚，又缩了回来：“可是……树林好黑呀。”

- 互动：拨开枝叶，接住星星。
- 发生的事：露露还是伸出了手：“我陪你去。”枝叶分开，星光只照亮脚边一小块。

### 第 2 幕：又是这棵歪树

“跑快点，就不怕了！”露露一口气跑出去，又绕回那棵歪树。树后还有两个摇晃的“角”……

- 互动：照一照树后的影子。
- 发生的事：露露停住脚，把星光照过去。哪有什么怪兽，只有两根弯弯的树枝！

### 第 3 幕：先走这么一点点

“我只能照亮这么一点点。”星星小声说。露露看看脚边：“那我们就先走这么一点点。”

- 互动：先走到小石头旁。
- 发生的事：露露走到小石头旁，停了停：“原来这里有个转弯。”

- 互动：沿着转弯再走一步。
- 发生的事：转过弯，一朵蘑菇露了出来。“下一步，走到你那里。”

- 互动：走到蘑菇旁边。
- 发生的事：一步，又一步。风吹动露露的耳朵，树梢变矮了——山顶就在前面！

### 第 4 幕：在天空中再见

山顶的晚风托起了小星星。“到家啦！”露露望着回去的路，耳朵又抖了抖。

- 互动：陪露露迈出第一步。
- 发生的事：“先走到那朵蘑菇旁边。”露露迈出一步。天上的小星星也眨了眨眼。

### 读完后，聊一聊

露露后来为什么能走出森林？

- 看清脚边，一次走一小段（故事中的原因）
- 闭上眼睛，一口气跑到底
- 等小星星照亮整片森林

回顾提示：想想那棵又遇见的歪树：跑得快没有走出去，露露后来怎样走的？

解释：星光没有变多。露露换了办法，看清下一步，再慢慢往前走。

纪念物：星光书签。夹住这一页，记住那一点刚好够走下一步的光。

## 鲸鱼与海的彼岸

妮可想把浪花里的亮光送给伙伴，可亮光一碰就散。她得想个新办法。

情节：想把亮光送给伙伴 → 越追越抓不住 → 发现阳光能照出水花里的彩虹 → 邀请伙伴一起看见。

### 第 1 幕：抓不住的礼物

浪花上跳着一片亮光。妮可想带回去送给伙伴，便甩着尾巴追过去：“抓住啦？”

- 互动：试着接住浪花里的光。
- 发生的事：哗啦！亮光碎成小点，从妮可的鳍边溜走。她慢下来，前面的浪花却又亮了。

### 第 2 幕：亮光躲到哪里了

“用珊瑚围住你呢？”妮可刚游过去，一朵云飘来，亮光忽然不见了。她抬起头……

- 互动：看看云后面。
- 发生的事：云一飘开，阳光落在水面上，亮光又回来了。“原来是太阳！可怎么把它带回去呢？”

### 第 3 幕：鼻尖上的主意

带不走亮光，妮可有点失望。刚叹了口气，鼻尖的小水珠竟闪出颜色。“再喷高一点呢？”

- 互动：朝阳光喷一口水。
- 发生的事：噗——阳光穿过水珠，弯出一道小彩虹。“有办法了！我要请伙伴们来看。”

### 第 4 幕：一起看见的礼物

妮可把伙伴们叫到有阳光的海面。“礼物在哪儿？”大家东张西望。妮可鼓起腮帮子。

- 互动：给伙伴们看小彩虹。
- 发生的事：小彩虹又挂在水珠上。“我带不走太阳，可是能请你们一起看！”一只小鲸鱼也学着喷了一小滴水。

### 读完后，聊一聊

妮可为什么能让伙伴看到小彩虹？

- 她游得比亮光快
- 阳光照进了她喷出的水珠（故事中的原因）
- 珊瑚把亮光围了起来

回顾提示：想想妮可鼻尖的小水珠：它遇见了什么，才出现颜色？

解释：妮可发现阳光能照出水花里的颜色，就请伙伴们一起来看。亮光带不走，这个办法却做到了。

纪念物：海洋书签。夹住这一页，记住大家一起看见的小彩虹。

## 云端的失物

可可捡到一只小铃铛，跟着叮铃声寻找主人。可那声音怎么总在学它？

情节：想帮铃铛找到主人 → 把回声当成了回应 → 停下来听见求助，再用丝带确认 → 归还铃铛，和主人一起迎接夜晚。

### 第 1 幕：捡到一声叮铃

可可最喜欢叮铃声。云朵上躺着一只小铃铛，绿丝带断了一头。“主人一定在找你。”

- 互动：摇两下，听听回应。
- 发生的事：可可摇了两下，远处也响了两下。“在那边！”它抱着铃铛跑过去。

### 第 2 幕：谁在学我说话

可可追到云海边，又摇了三下。那边也一模一样地响了三下，连一句话都没有。

- 互动：先停下来听一听。
- 发生的事：“原来是我自己的回声。”可可不摇了。风里传来一句：“我的绿丝带铃铛呢？”

### 第 3 幕：两截绿丝带

可可循着说话声，找到一颗着急的小星星。它手上也系着半截绿丝带。“你丢的是这只吗？”

- 互动：把两截丝带凑一凑。
- 发生的事：两截丝带刚好对上。可可把铃铛递过去：“我差点跟着回声找了一整夜呢！”

### 第 4 幕：摇响夜晚的铃铛

小星星系好铃铛：“有了它，我就能叫醒值夜班的星星。你愿意帮我摇第一声吗？”

- 互动：一起摇响晚安铃。
- 发生的事：叮铃！远处亮起一颗，又一颗。“这回可不是回声。”可可笑了，也轻轻说了一声：“晚安。”

### 读完后，聊一聊

可可后来为什么找到了铃铛的主人？

- 它摇得更响，回声就带路了
- 它让每朵云都试戴了铃铛
- 它停下摇铃，听见了说话声（故事中的原因）

回顾提示：叮铃声总在重复可可的动作。铃铛安静以后，它听到了什么？

解释：回声只会学铃铛响。可可停下来，才听见主人在找铃铛；两截绿丝带又帮它认对了主人。

纪念物：云朵书签。夹住这一页，记住可可停下来听见的那句话。
